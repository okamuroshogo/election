# おかむーの選挙活動リポジトリ（公開）

データと透明性で政治を前に進める。
このリポジトリでは、国のために活動するコード・分析・政策提案を公開しています。

---

## 政策一覧

### 1. 分析省・データ政策

| 政策 | 概要 |
|------|------|
| **分析省** | 政策は勘と空気で決めない。データで現状を可視化し、議論を前に進める「分析省」を新設する |
| **公開分析** | 日本の課題を「数字で説明できる形」で毎週公開。都合のいい切り取りではなく、元データと前提も出す |
| **公共メディア** | 政策の根拠を説明するチャンネルを作る。印象戦ではなく、データと比較で判断できる社会へ |
| **テクノロジーで最適選択** | AIとデータで政策の効果を予測・検証。勘ではなく改善サイクルで国を運営する |

### 2. 選挙・投票改革

| 政策 | 概要 |
|------|------|
| **投票日は祝日** | 投票日を祝日にして投票率を上げる。忙しさを言い訳にしない制度設計へ |
| **選挙をお祭り化** | 投票会場の周辺で文化イベント（例：アーティストのライブ）。政治を「参加するもの」に変える |
| **公開討論** | 投票日に与党・野党・市民の公開討論を標準化。双方の意見を同じ場所で聞ける仕組みに |
| **台湾の事例** | 選挙を「参加の祭り」にする発想はヒントがある。日本も投票を生活の中心イベントへ |

### 3. 政治家の評価と透明性

| 政策 | 概要 |
|------|------|
| **初心表明演説** | 就任時に「何をいつまでにやるか」を数値で宣言。言いっぱなしを終わらせる |
| **決算発表演説** | 年度末に「できた/できない」を決算発表。失敗の理由と次の手もセットで説明する |
| **公開年俸制** | 政治家の報酬は成果と説明責任に連動。年俸は公開し、制度として評価できるようにする |
| **アプリ投票で年俸** | 政治家の年俸の一部を市民評価で変動。人気投票ではなく、根拠付き評価を必須に |
| **年俸を下げる時のルール** | 下げる場合は「根拠」と「代案（自分ならこうする）」の記述を必須化。感情だけで決めない |
| **見える化担当大臣** | 各省の事業を可視化する「見える化担当大臣」を設置。成果・コスト・副作用を公開する |
| **政治家の専門性** | 政策分野ごとの専門性を公開し、評価される仕組みに変える |

### 4. 民主主義の活性化

| 政策 | 概要 |
|------|------|
| **与党野党の役割** | 批判のための批判を終わらせる。対案と検証で競争し、解決策を積み上げる国へ |
| **相互尊重の政治** | 国民同士が尊重して議論できる環境を作る。分断を煽る政治から卒業する |
| **民主主義を活性化** | 参加・検証・改善が回る仕組みを制度として作る |
| **敵は古い独裁慣習** | 情報が限られ、選択肢が見えない政治を終わらせる。本物の民主主義を作る |
| **意見はみんなある** | 全員の言い分を"ぶつける"のではなく、"比較して調整する"。長期成長を軸に合意形成する |

### 5. 経済・成長戦略

| 政策 | 概要 |
|------|------|
| **成長のシーソー** | シーソーが動かなければトロッコは進まない。痛みの分配は、透明なルールと補償で支える |
| **IT企業への税制優遇** | 成長産業に投資が回る税制へ。国内で挑戦する企業が報われる制度に変える |
| **高度人材の減税** | 海外の高度技術者が日本で働きやすい税制へ。人材獲得競争で負けない国にする |

### 6. 移民・国際化

| 政策 | 概要 |
|------|------|
| **移民受け入れ** | 人手不足は現実。ルールを明確にし、受け入れと統合政策をセットで進める |
| **英語の壁** | 受け入れ政策は言語が鍵。英語教育と行政手続きを整え、現場が回る設計にする |
| **第二公用語を英語** | 国際競争力を上げるため、英語を第二公用語へ。段階導入と現場支援をセットで |

### 7. 教育改革

| 政策 | 概要 |
|------|------|
| **古文漢文を見直す** | 入試・授業の配分を見直し、情報（プログラミング/統計/リテラシー）を厚くする |
| **漢字の簡素化** | 学習コストの高い旧字体偏重を見直す。読み書きの負担を下げ、実務能力に振る |

## このリポジトリについて

- 政策の根拠となるデータ分析・コードを公開しています
- 都合の良い解釈ではなく、元データ・前提・手法をセットで提示します
- Issue / Pull Request による議論を歓迎します
